# Configuration Files

This directory contains configuration files for the resume project.

## courses.json

The `courses.json` file contains a list of all professional development courses and certifications. This file is automatically generated from the course data in the `astro-portfolio-mdx` project.

### Structure

```json
{
  "lastUpdated": "2025-12-15T15:38:45.196Z",
  "totalCourses": 21,
  "courses": [
    {
      "id": "course-slug",
      "title": "Course Title",
      "teacher": "Instructor Name",
      "description": "Course description",
      "duration": "5h 30m",
      "level": "intermediate",
      "category": ["javascript", "frontend"]
    }
  ],
  "coursesByTopic": {
    "JavaScript & Web Development": ["Course 1", "Course 2"],
    "TypeScript": ["Course 3"]
  }
}
```

### Refreshing Course Data

```bash
npm run refresh-courses
```

This script:

1. Reads all `.mdx` files from `~/Documents/Workspace/astro-portfolio-mdx/src/content/courses`
2. Extracts course metadata (title, teacher, description, duration, level, categories)
3. Groups courses by topic based on their primary category
4. Writes the data to `courses.json`

## projects.json

The `projects.json` file contains a list of all personal and professional projects. This file is automatically generated from the project data in the `astro-portfolio-mdx` project.

### Structure

```json
{
  "lastUpdated": "2025-12-15T15:42:09.084Z",
  "totalProjects": 5,
  "projects": [
    {
      "id": "project-slug",
      "title": "Project Title",
      "description": "Project description",
      "liveLink": "https://example.com",
      "tags": ["AI", "web development"]
    }
  ],
  "projectsByTag": {
    "AI": ["Project 1", "Project 2"],
    "web development": ["Project 3"]
  }
}
```

### Refreshing Project Data

```bash
npm run refresh-projects
```

This script:

1. Reads all `.md` files from `~/Documents/Workspace/astro-portfolio-mdx/src/content/projects`
2. Extracts project metadata (title, description, liveLink, tags)
3. Skips projects marked as `hidden: true`
4. Groups projects by tags
5. Writes the data to `projects.json`

## Refresh All Data

To update both courses and projects at once:

```bash
npm run refresh-all
```

## Manual Editing

While you can manually edit these JSON files, it's recommended to:

1. Update the source files in the `astro-portfolio-mdx` project
2. Run the appropriate refresh script to regenerate the files

This ensures consistency between projects and makes it easier to maintain data in one place.
